# NikiRent — дашборд обращений

## Запуск на компьютере
1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Выполните:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. Откроется браузер с дашбордом.

## Публикация бесплатно через Streamlit Community Cloud
1. Создайте аккаунт GitHub и новый репозиторий.
2. Загрузите в репозиторий `app.py`, `requirements.txt` и папку `data` с `nikirent_source.xlsx`.
3. Откройте https://share.streamlit.io/ и войдите.
4. Нажмите Create app, выберите репозиторий, ветку `main` и файл `app.py`.
5. Нажмите Deploy. После публикации появится публичная ссылка `*.streamlit.app`.

Важно: исходная таблица не подключается по API и не изменяется. Новые данные загружаются через боковую панель приложения в формате XLSX/XLS/CSV.
